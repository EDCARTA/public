## [1.10.0] - 2026-06-17

This release was focused on incremental improvements to the project management module and other general updates.

### Added

- Visual indiciation of projects coming due within 3 days
- Tasks can now have comments
- Tasks can be duplicated
- Removed character limit on project notes
- Added task checklists
- Added My Tasks page
- Enhancements to project filters
- Invited users can now access private projects

### Fixed

- Long project names no longer result in an unintended indentation in the projects table view
- Cleared due date on project tasks no longer shows as late on kanban

### Removed
